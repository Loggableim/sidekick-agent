# v0.8.83 — WebUI reliability and CI stabilization

**Release date:** 2026-07-26

## Fixed

- Restored the single-click workflow palette trigger and bounded its menu on
  desktop, avoiding duplicate or hidden header controls.
- Treat attached `about:blank` browser sessions as an intentional empty state;
  stale frames, cursors, and click flashes are cleared until navigation starts.
- Keep the workflow status chip in sync when the browser drawer opens or
  closes, even when the compact browser status badge is not rendered.
- Restored asynchronous Game Mode title generation by matching the canonical
  Unicode title placeholder.
- Declared `tzdata` so Windows installations can resolve IANA time zones.
- Repaired stale smoke checks for the canonical Sidekick home, session, and
  branding contracts.

- `python tests/smoke_all.py` — 22 passed, 0 failed
- `python tests/smoke_webui.py` — 14 passed, 0 failed

No manual migration is required. Existing Sidekick state remains in
`~/.sidekick`; installing this release also brings the timezone database needed
on Windows systems.
